The workbench

The whole diagnostic thread, without digging through chat.

See the current assessment, next test, ranked hypotheses, local sources, and completed work in one place. Cases survive restart and export to a readable Markdown record.

  • Persistent stateCase history stays in local SQLite storage.
  • Grounded cardsProcedure references come from the bundled local index.
  • Visible guardrailsRepeat and data-risking steps cannot pass silently.

Advisory by design

Advice stays advice.

Field Tech Copilot never runs a command or changes a customer’s machine. It blocks silent repeat tests, labels risky steps, and requires technician confirmation before destructive or data-risking work.

Pre-alpha software can be wrong.

A trained technician must verify every recommendation and remains responsible for customer data and repair decisions.

Do not enter passwords, recovery keys, payment data, or unrelated customer files.

  3. 3

    It opens in your browser only on this PC at 127.0.0.1.

SHA-256

Verify in PowerShell:

Get-FileHash .\FieldTechCopilot-FieldKit-Lite-*.exe -Algorithm SHA256
Why “Lite”?

The one-file kit uses an official, redistributable 1.7B Qwen model so it fits under GitHub’s 2 GiB asset limit. It is for workflow evaluation and is not validated for field diagnosis. The existing Ollama + Qwen3 8B profile remains the higher-quality option and requires a separate model download before going offline.
